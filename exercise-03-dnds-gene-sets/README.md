# Exercise 3: comparison of dN/dS ratios among gene sets

This exercise compares the distribution of dN/dS ratios among three human gene sets:

- Complement system
- Splicing
- Neurogenesis

The analysis was performed in R using Ensembl BioMart and Gene Ontology annotations.

## Files

- `Exercise3_DnDs_gene_sets.R`: R script containing the analysis.
- `HumanDnDsW.txt`: input data containing the dN, dS and dN/dS values.

## Required R packages

- biomaRt
- GO.db
- AnnotationDbi
- dplyr
- ggplot2
- viridis
